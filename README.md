# Deep Rooted

Deep Rooted.Co is a direct-to-consumer fresh produce brand operated by Clover Ventures Pvt. Ltd, a Bengaluru-based agritech company founded in 2018 that launched the Deep Rooted consumer brand in 2020. The company partners with small-scale farmers using greenhouse and hydroponic techniques within roughly 150km of Bengaluru and Hyderabad, provides agronomy support from seed to harvest, and delivers fruits, vegetables, Indian staples and greens, exotic produce, and an easy-cook range next-day to households in both cities.

Website: https://deep-rooted.co/ — Backed by: accel

## API surface

Deep Rooted publishes **no public API**: no developer portal, no API documentation, no SDKs, no CLI, and no machine-readable specification. Probes on 2026-07-20 returned 404 for `/llms.txt`, `/openapi.json`, `/swagger.json`, `/api`, and every `/.well-known/` discovery document. The consumer storefront is a web/mobile ordering experience built on third-party vendors (Razorpay, UrbanPiper, Freshchat). This profile therefore captures company identity and web properties only.

Note: the domain `clover.ag`, previously recorded here as the company website, is now a parked domain listed for sale; `deeprooted.co` returns a Cloudflare origin error. The live property is `deep-rooted.co`.
